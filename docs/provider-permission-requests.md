Prepared 2026-10-10. These are drafts, not sent messages, licence grants or purchases. Choose the product audience and budget in the restart report before sending. A yes to API access is separate from a yes to storage, public display or external-model processing.

## football-data.org

Subject: Permission for a small Arsenal briefing application

Hello,

I am building Sports Briefing, a small personal project following Arsenal. The current integration uses your Premier League and Champions League fixture/result data. I would like to confirm whether my subscription permits a public, non-commercial website and a companion mobile application using one application key.

The application stores the latest normalized fixture state in SQLite and shows at most two selected items, with your required attribution. It does not expose your raw API or resell data. Please confirm whether this storage/cache and public display are permitted, any refresh/deletion obligations, and what must be removed after cancellation.

Separately, may selected minimal fixture facts be sent to an external model API to produce a short summary? If permitted, please specify retention, attribution and derived-summary restrictions. The first release can use deterministic templates and send nothing to a model.

Please also confirm the plan required for the intended competitions and live versus delayed data.
